# 一键把 Kimi K3 接入 Codex（最新教程）

Kimi K3 火爆全网，由于用户数量暴增，官方已经暂停接受新的 **Kimi Work** 会员申请。

如果想继续使用 **Kimi K3**，目前最简单的方法就是：

> **通过 API 接入第三方 Agent，例如 Codex。**

本教程将演示如何将 **Kimi K3 API 接入 Codex**，全程仅需几分钟。

---

# 第一步：开通 Kimi API

打开 Kimi 开放平台：

https://platform.kimi.com

首次注册通常会赠送 **15 元余额**。

> **注意：**
>
> - 赠送余额**不能用于 Kimi K3**
> - 如果要使用 **Kimi K3**，至少需要充值 **50 元**

充值完成后即可调用 K3 模型。

---

# 第二步：下载 CC-Switch

前往 GitHub Releases 页面：

https://github.com/farion1231/cc-switch/releases

下载：

**Windows-Portable.zip**

这是免安装版本。

下载完成后：

1. 解压压缩包
2. 双击运行 **CC-Switch.exe**

无需安装。

---

# 第三步：配置 Kimi

打开 **CC-Switch**。

找到：

> **Kimi**

然后：

1. 输入你的 API Key
2. 选择 **Kimi K3**
3. 点击保存
4. 启动代理

保持 CC-Switch 一直运行即可。

---

# 第四步：重新打开 Codex

确保 **CC-Switch 正在运行**。

然后重新启动 **Codex Desktop App**。

Codex 会自动连接到 CC-Switch，并开始使用 **Kimi K3**。

---

# 完成

至此，你已经成功把 **Kimi K3** 接入 **Codex**。

以后只需要：

- 打开 CC-Switch
- 打开 Codex

即可直接使用 Kimi K3，无需再登录 Kimi Work。

---

## 常见问题

### Q：为什么 Codex 找不到模型？

请确认：

- CC-Switch 已启动
- API Key 正确
- 已选择 Kimi K3
- 账户余额充足

---

### Q：15 元赠送余额可以使用 K3 吗？

不可以。

赠送余额只能用于部分旧模型。

使用 **Kimi K3** 需要自行充值（目前至少 50 元）。

---

### Q：需要安装 CC-Switch 吗？

不需要。

下载 **Windows-Portable.zip** 后解压即可直接运行。

---

整个流程非常简单：

1. 开通 Kimi API
2. 充值 K3 所需余额
3. 下载并运行 CC-Switch
4. 配置 API Key 和 Kimi K3
5. 重启 Codex

现在就可以在 Codex 中体验 Kimi K3 的强大能力。
